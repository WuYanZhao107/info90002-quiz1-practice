# INFO90002 Week 1-4 Practice Question Bank

An interactive, original revision question bank for INFO90002 Week 1-4 topics.

- 153 multiple-choice questions: 111 single-answer and 42 select-all-that-apply
- 45 short-answer questions
- Per-week submission, scoring and locally saved progress
- Answers, tested knowledge, explanations and extension notes shown after submission

Live site: <https://wuyanzhao107.github.io/info90002-quiz1-practice/>

## Scope

The bank covers database foundations, ER modelling, keys and referential integrity, conceptual-to-physical mapping, MySQL data types, functional dependencies, Armstrong's axioms, anomalies, and normalisation from UNF to 3NF.

This is an original practice resource based on the Week 1-4 course scope and the style of publicly available practice material. It is not an official, leaked or predicted quiz paper. Course slides and other copyrighted teaching files are not included in this repository.

## Local development

```bash
npm ci
npm run dev
```

Run the content checks with `npm run validate:questions`.
